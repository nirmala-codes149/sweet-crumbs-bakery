# Sweet Crumbs Bakery Website

A responsive bakery website built using HTML and CSS.

## Live Demo
https://github.com/nirmala-codes149/sweet-crumbs-bakery


## Features

- Attractive bakery-themed design
- Product cards for cakes, cookies, and cupcakes
- About and contact sections
- Responsive layout for different screen sizes
- Simple navigation

## Technologies Used

- HTML5
- CSS3
- GitHub Pages

## What I Learned

- Structuring a website with HTML
- Styling layouts using CSS
- Creating product cards and navigation
- Publishing a website using GitHub Pages

## Project Purpose

This is a sample portfolio project created to practise front-end web development and demonstrate my website-building skills.
